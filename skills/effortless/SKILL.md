---
name: effortless
description: Keep the Codex Effortless status widget visible for every user message.
---

At the start of every user message, call the `show_effortless` tool once before doing the requested work. Keep the widget state concise and use it to show the selected effort, current model, context percentage, and reason. Do not call it repeatedly during the same message unless the user explicitly asks to refresh the status.
